# Hi, I'm the founder of Pixelbot Studio 👋

**Founder & full-stack developer** · Nagpur, India · working with clients worldwide

[Pixelbot Studio](https://pixelbotstudio.com) is a branding, packaging and e-commerce studio. We build brand systems and the products they live on: custom online stores, web applications and AI-powered tools for food, wellness, lifestyle and D2C companies.

> *The same brand on the shelf and on the screen.*

## What I build

- **Custom web applications:** multi-app platforms with authentication, role-based access, payments and admin consoles
- **AI-powered products:** health and wellness assistants, using the Claude API with attention to safety and privacy
- **E-commerce:** Shopify stores and custom Next.js storefronts
- **Developer tooling:** I open-source what I learn, such as [PreflightKit](https://github.com/parag0508-lang/preflightkit)

## Featured open-source project

### [PreflightKit](https://github.com/parag0508-lang/preflightkit): *Is your app ready to ship?*
A free security and launch-readiness toolkit: a checklist, guides for 8 frameworks plus AI/LLM apps, a scanner CLI (`npx preflightkit`), a GitHub Action, and a pack of Claude skills.
